# 🫁 Lung Cancer Detection Using Deep Learning

## 📌 Project Overview
Lung Cancer Detection Using Deep Learning is an intelligent healthcare application developed to assist in the early prediction and identification of lung cancer symptoms using machine learning and deep learning techniques.

This project is designed to analyze patient symptoms and CT scan related inputs for efficient diagnosis support.

---

## 🚀 Features
- Deep learning based lung cancer prediction
- Symptom checker for preliminary diagnosis
- Automated patient result generation
- Medical support assistance using AI
- Fast and user-friendly Python implementation

---

## 🛠️ Technologies Used
- Python
- TensorFlow
- Keras
- CNN
- Machine Learning
- NumPy
- Pandas

---

## 📂 Project Files
- `app.py` – Main application interface
- `modeltraining.py` – Model training process
- `prediction.py` – Prediction module
- `symptomchecker.py` – Symptom analysis system

---

## 🎯 Objective
To build an AI-powered healthcare assistant capable of supporting doctors and patients with early-stage lung cancer identification.
